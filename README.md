Ассистент руководителя, отчёты по компании в Телеграм.

Бот для директора управляющей компании: собирает данные из CRM («Бурмистр.ру»), находит «красные точки» и присылает в Telegram короткий голосовой отчёт (~45 секунд), а полный отчёт — на почту. На уточняющие вопросы отвечает голосом.

## Пример отчёта — открыть и прочитать

Первая версия работает на выдуманных (мок) данных: 3 отдела, 8 сотрудников, 5 домов, 22 задачи.

- [Короткий отчёт](examples/короткий_отчёт.txt) — разговорным языком, для голосового сообщения
- [Полный отчёт](examples/полный_отчёт.md) — красные точки, таблицы по отделам, сотрудникам, домам, платежи
- [«Подробнее про Соколова»](examples/подробнее_Соколов.md) — ответ на запрос деталей по сотруднику

Собрать самому (Windows): двойной щелчок по **«Показать пример отчёта.bat»** или

```bash
python -m agent.demo
```

## Что умеет боевая версия

- **Отчёт по расписанию** (пн и пт) и **по запросу** («сделай отчёт», «за месяц»): период — с прошлого отчёта.
- **Источники:** заявки жителей, реестр задач директора, входящая корреспонденция (выгрузки из CRM).
- **Красные точки:** отключения на весь дом, перегруженные сотрудники, задачи на проверке у директора, просрочки, запросы госорганов, претензии и финансовые риски.
- **Голос:** вопросы голосом → короткий ответ голосом; поручения голосом с подтверждением.
- **Персональные данные жильцов** (ФИО, телефоны, почта, лицевые счета) удаляются до анализа.

## Устройство

| Путь | Что это |
|---|---|
| `agent/company.py`, `agent/digest.py`, `agent/demo.py` | Первая версия: единый формат данных и отчёт по правилам на мок-данных |
| `data/mock/company.json` | Мок-данные компании |
| `agent/sources.py` | Чтение выгрузок CRM, очистка персональных данных, сводка за период |
| `agent/analyze.py` | Анализ через Claude: голосовая сводка, полный отчёт, ответы на вопросы |
| `agent/bot.py` | Telegram-бот: расписание, отчёт по запросу, голосовые вопросы |
| `agent/commands.py` | Поручения голосом: разбор, подтверждение, очередь |
| `agent/voice.py`, `agent/stt.py` | Озвучка (edge-tts) и распознавание речи (faster-whisper, локально) |
| `tools/` | Скрипты для выгрузки из CRM через браузер |

## Запуск

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
```

В `.env` вписать ключи (Claude API, Telegram-бот, почта), затем запустить бота: **«Запустить агента.bat»**. Подробности — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

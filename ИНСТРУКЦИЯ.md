# Как устроен агент

## Что умеет ассистент

- Собирает сводку по делам компании: задачи и заявки по отделам, сотрудникам и домам, платежи жителей.
- Находит «красные точки»:
  - срочные аварийные задачи;
  - вопросы, где нужно решение руководителя;
  - просрочки;
  - повторные заявки по одному дому;
  - перегруженных сотрудников;
  - низкую собираемость платежей.
- Готовит два отчёта:
  - **короткий**, разговорным языком: его можно озвучить и прислать голосовым;
  - **полный**, со всеми цифрами и списком задач.
- Отвечает на запрос «подробнее про…»: по сотруднику, отделу, дому или номеру задачи.

## Две версии отчёта

| | Пример на мок-данных | Боевая версия |
|---|---|---|
| Данные | `data/mock/company.json`: выдуманная УК, 3 отдела, 8 сотрудников, 5 домов, 22 задачи | Выгрузки из Бурмистра в `data/inbox/`, позже 1С |
| Кто пишет отчёт | Правила в `agent/digest.py`, без интернета и бесплатно | Нейросеть Claude (`agent/analyze.py`), нужен ключ |
| Как посмотреть | Двойной щелчок по **«Показать пример отчёта.bat»** | Телеграм-бот (**«Запустить агента.bat»**) |
| Где результат | `reports/пример/`: `короткий.txt`, `короткий.mp3`, `полный.md` | `reports/<дата>/` |

Новые источники (CRM, 1С) приводятся к единому формату из `agent/company.py`. После этого отчёт строится тем же кодом.

## Что где лежит

| Папка / файл | Что это |
|---|---|
| `data/inbox/` | Сюда кладутся выгрузки из Бурмистра (Excel или CSV). Агент забирает всё, что там лежит. |
| `data/archive/<дата>/` | Сюда агент переносит выгрузки после того, как сделал по ним отчёт. |
| `reports/<дата>/` | Готовые отчёты: `report.md` — полный, `voice.mp3` — голосовой, `data.md` — данные без персональных данных жильцов. |
| `.env` | Настройки и ключи доступа. Никому не пересылать. |
| `Запустить агента.bat` | Двойной щелчок запускает бота. Окно должно оставаться открытым. |
| `agent.log` | Журнал работы, по нему ищем ошибки. |

## Как проходит день

1. Утром выгрузка заявок и задач из Бурмистра попадает в `data/inbox/`. Пока это делается вручную, позже будет делать Claude в Chrome.
2. В назначенное время (по умолчанию в 8:00) агент:
   - читает выгрузки и убирает из них ФИО, телефоны и почту жильцов;
   - отдаёт данные на анализ Claude;
   - присылает в Телеграм голосовой отчёт, а на почту полный.
3. В течение дня в бота можно написать любой вопрос по отчёту.

## Команды бота

- `/start` — приветствие (при первом запуске бот сообщит номер вашего чата)
- `/report` — собрать отчёт прямо сейчас

## Безопасность

- Бот отвечает только владельцу: чату с номером из `TELEGRAM_CHAT_ID`.
- Персональные данные жильцов не уходят на анализ.

## Сколько это стоит и как удешевить

Замеры от 15.10.2026 на реальных данных (Claude Opus 5.5, расходы пишутся в базу, в боте — команда `/db`):

| Что | Настройка | Цена |
|---|---|---|
| Отчёт, глубокий анализ | `REPORT_EFFORT=high` | ~$0.64 |
| Отчёт, облегчённый | `REPORT_EFFORT=medium` | ~$0.43 |
| Вопрос: Opus, отчёт + вся сводка | `QA_CONTEXT=full` | ~$0.41 |
| Вопрос: Opus, только отчёт (по умолчанию) | `QA_CONTEXT=report` | ~$0.19 |
| Вопрос: Sonnet, только отчёт | `QA_MODEL=claude-sonnet-5-5` | ~$0.07 |
| Вопрос: Haiku, только отчёт | `QA_MODEL=claude-haiku-5-5` | ~$0.003 |

Цена — для первого вопроса после отчёта: Claude один раз «запоминает» отчёт (кэш на час),
следующие вопросы в течение часа дешевле. Настройки меняются в `.env`, после правки
бота нужно перезапустить.

## Сторож

Задание Планировщика Windows «Ассистент руководителя - сторож»: при входе в Windows и
каждые 10 минут запускает бота, если он не работает (вторую копию бот сам не допускает).
